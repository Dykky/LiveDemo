# Sistem Catatan Keuangan Harian

Program ini merupakan aplikasi sederhana berbasis **Java console** untuk mencatat keuangan harian.
Dikembangkan untuk latihan konsep **Object-Oriented Programming (OOP)** dan **JavaDoc Documentation**.

---

## Fitur Program

✅ Tambah catatan keuangan (pemasukan/pengeluaran)  
✅ Lihat daftar seluruh catatan keuangan  
✅ Hapus catatan berdasarkan nomor  
✅ Lihat total saldo (pemasukan - pengeluaran)  
✅ Dokumentasi kode menggunakan **JavaDoc**

---
